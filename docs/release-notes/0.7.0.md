# Runfree 0.7.0

0.7.0 adds headless runs. `runfree run` runs one agent turn from launchd, a
script, or a detached pane, and returns an exit code a scheduler can act on.
The release also lets you set request rules on a host that a service allows,
adds a `google-search-console` service with a host-signed service-account
credential, and mediates MCP OAuth token endpoints on another host. Config
version 4 is unchanged.

- New `runfree run claude|codex|pi --prompt-file <file>` starts a normal
  session without a terminal, never prompts, and maps the agent's JSON event
  stream to reserved exit codes (64–68). The proxy denies `ask` writes from a
  headless session at once; `run` refuses before the launch unless every write
  resolves to `allow` or `deny`, or you pass `--accept-denied-writes`. Each run
  keeps a host-only record, and one run at a time holds a project lock.
- `runfree host rules <host>` now works on a host that an enabled service
  allows, such as `runfree host rules github.com --deny-git-push`. The setting
  is stored with the service and laid over the service's rule.
- New `google-search-console` service and
  `runfree credential source add google-service-account`. The host signs a
  Google service-account JWT; the key JSON stays in 1Password.
- `runfree mcp enable` accepts an OAuth token endpoint on another host when
  the server's own metadata names it, and the proxy mediates it. The proxy now
  refuses an OAuth token or registration request it does not mediate on a host
  that only MCP records allow. `runfree doctor` names this refusal.
- `runfree service explain <id>` works for any service, enabled or not, and
  prints the service's setup notes.
- Directories under the agent's home that hold Runfree's mount targets are
  owned by the agent, not root, so pnpm can install a pinned pnpm version.
- Claude Code 2.1.310, Codex 0.164.0, Pi 1.4.0, and uv 0.13.5 in the agent
  image.
- **Breaking:** `runfree mcp enable` no longer runs the OAuth login. It
  prints the `runfree mcp auth` command; pass `--login` to run it at once.
  `runfree service explain` prints text; pass `--json` for JSON.
- **Upgrade:** a `host rules` setting on a service host writes
  `.runfree/network-policy.json` as version 4, which 0.6.x refuses, so
  upgrade every team member before you commit one. The proxy's admission
  contract changed: end running sessions before the first start, or run
  `runfree rebuild`. The first start rebuilds the agent image.
