# Runfree 0.5.2

0.5.2 is a release-process release. It changes how a release is gated, not what
Runfree does at runtime. The CLI, proxy, agent image, config format, and policy
format are the same as in 0.5.1. v0.5.1 was published from a commit that later
failed the Test workflow's static checks, because the release lane ran unit
tests only. The release lane now runs the full Test verification at the
release commit before it builds or publishes anything.

- The release lane calls the same `verify.yml` workflow as the per-commit Test
  workflow, at the resolved release SHA. Static checks, unit tests, template
  validation, and the offline packaged E2E lane must pass before the macOS
  builds start.
- New `make test-release` target runs those checks locally before a tag is
  pushed. It needs the Docker CLI and Bun, but not a Docker daemon.
- Fixed the Biome unused-variable failure that broke `make test-static` on the
  v0.5.1 release commit.
- The E2E scenarios LH-09, LH-12, and LH-23 are now `Partial` instead of
  `Implemented-failing`, because the defects they tracked are fixed.
- No upgrade warning. There are no breaking changes and no migration steps.

Details: [`docs/whats-new-0.5.2.md`](../whats-new-0.5.2.md).
