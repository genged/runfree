# Runfree 0.8.0

0.8.0 adds Linux support and lets scheduled runs read 1Password without a
prompt. Linux on arm64 and x64 with native Docker Engine is supported, with
published binaries. A new 1Password connection source logs in with a service
account, and `runfree run` refuses any credential source that may ask a
person. Config version 4 is unchanged.

- Linux (arm64 or x64, glibc) with Docker Engine is supported. The install
  script installs the Linux binaries. Host services work on Linux through a
  host relay container.
- New `runfree credential source 1password <name>` keeps a 1Password
  service account token in the macOS login Keychain. Bind a reference through
  it with `--via <name>` on `credential set-source`, `credential add`,
  `service enable`, and `mcp enable`. `credential source check` and
  `credential source login` check and rotate the login.
- `runfree run` refuses (65), before Docker starts, a credential source that
  may ask a person: a 1Password desktop-app read or a command source.
  `credential status` shows whether a run can read each binding.
- A headless run whose agent does not exit 30 seconds after its final event
  is stopped and keeps that event's result.
- Ctrl-C, SIGTERM, or a closed terminal now stops and tears down an attached
  session. A closed terminal exits 129.
- A session started by an older Runfree keeps running after a CLI upgrade. A
  session also keeps running when the kernel kills one of its child
  processes for lack of memory.
- `credential status` and `credential source show` print `1password` in
  place of an `op://` reference. Pass `--show-refs` to print the reference.
- Runfree writes `.runfree/network-policy.json` indented, with fields in a
  fixed order, so a one-host change is a small diff.
- Claude Code 2.1.322, Codex 0.167.2, and Pi 1.5.2 in the agent image.
- **Breaking:** a Pi launch first reviews the new `agent-pi` service, which
  allows Pi's read-only model catalog. `runfree run pi` refuses until you run
  `runfree service enable agent-pi`.
- **Upgrade:** Runfree 0.7.x refuses a credential binding saved with `--via`.
  The first command that writes the network policy reformats the whole file
  once; it needs no new approval. The first start rebuilds the agent image.
