# Runfree 0.6.0

0.6.0 adds four features. Host services let the agent reach a TCP service on
your machine's loopback. Git over HTTPS works with proxy-held GitHub and
GitLab tokens. `runfree mcp enable` sets up an MCP server in one review. And
`runfree resume` resumes interrupted work from the same terminal. The release
also cuts work from warm launches, gives each session its own MCP OAuth
callback port, and fixes many credential, MCP, recovery, and teardown edge
cases. Config version 4 is unchanged.

- New `runfree host-service` commands approve a host loopback port per
  project. Clients in the agent use it unmodified at `127.0.0.1:<port>`. The
  tunnel is opaque: no request rules, write approval, or credential injection
  apply to it.
- `git clone`, `fetch`, `pull`, and `push` over HTTPS work with the `github`
  and `gitlab` services. The proxy adds the token as HTTP Basic auth only on
  git smart-HTTP and Git LFS requests. GitHub and GitLab SSH remotes are
  rewritten to HTTPS inside the sandbox.
- New `runfree mcp enable` approves a project entry, binds its credential
  source, discovers its OAuth hosts, applies the change to a running proxy, and
  runs the login, after one review. `runfree mcp revoke` removes exactly those
  hosts and clears the proxy's OAuth state for the server.
- Loopback HTTP MCP servers (`http://127.0.0.1:<port>/...`) now import without
  credentials.
- `runfree resume` asks one question when the interrupted work clearly belongs
  to this terminal, and shows a labelled picker otherwise. Claude and Pi
  sessions now start with a conversation id that the host chooses.
- User-defined services can use the `basic` scheme, a `username`, and a
  `git-http` or `git-lfs` protocol scope.
- Host Git older than 2.48 no longer blocks a launch. Runfree warns instead,
  and refuses only worktree layouts that old Git cannot read.
- **Breaking:** `runfree mcp approve` is removed. Use
  `runfree mcp enable <agent> <server> --source project`.
- **Upgrade:** `.runfree/network-policy.json` may now be written as version 3.
  Runfree 0.5.x refuses a version 3 file and a file with a `hostServices`
  entry, so upgrade every team member before you commit either. Run
  `runfree service diff --apply` to get git mediation on an existing `github`
  or `gitlab` service. Bitbucket LFS downloads now wait for write approval
  under `ask`. Each MCP OAuth server needs one new login after the upgrade.
